# Recruitment through AI Tech Agent

An AI-powered recruitment platform that helps with the interview and candidate evaluation process.

## Features

- AI-based interview question generation
- Candidate interview and evaluation
- Automated scoring
- Support for multiple programming domains
- Dataset-based question generation

## Technologies

- Python
- Flask
- HTML / CSS
- JavaScript
- AI / LLM
- Ollama
